Antes: 11/11/2026 (PR #42).

**Como ler**
- **Situação** usa a mesma escala de [`status-requisitos.md`](status-requisitos.md):
  - `feito`: toda camada que garante a regra (banco, serviço ou API) tem teste, e há run do CI;
  - `parcial`: falta uma parte do requisito ou uma camada;
  - `ausente`: nenhuma camada que garante a regra tem teste.
  - Teste só de tela não tira um requisito de `ausente`, exceto o RF-13, que é um requisito da própria tela. Decisão do grupo ainda pendente aparece na linha, mas não rebaixa a situação quando o comportamento atual está testado.
- **Teste** cita só classes e métodos que existem no repositório, conferidos pelo nome em 12/11/2026. A camada vem entre colchetes:
  - [banco]: PostgreSQL em Testcontainers, SQL direto, `src/test/java/br/com/senac/recursos/banco`;
  - [API]: MockMvc com token de cada perfil (ou HTTP real, no teste de concorrência) contra PostgreSQL em Testcontainers, `.../controller`;
  - [serviço] e [unidade]: `.../service`, `.../model`, `.../enums`, `.../converter`;
  - [tela + banco]: telas com o usuário na sessão contra PostgreSQL real (`TelasComBancoTest`) ou servidor real com CSRF e cookie;
  - [tela]: teste de contrato do HTML (recorte `@WebMvcTest`), `.../web`;
  - [E2E]: Playwright em 375 px, `.../e2e`;
  - [carga]: JMeter em modo CLI, local, `perf/`.
- **Evidência:**
  - O run **43303372662** (GitHub Actions, run 221, job `verify` e SonarCloud verdes, commit `6ce4478` da `main`, 12/11/2026) roda todos os testes citados, menos a carga.
  - O mesmo commit no `./mvnw -B verify` local (12/11/2026): **1116 testes, 0 falhas, 0 erros, 0 ignorados**.
  - A carga não roda no CI; a evidência dela é o `.jtl`.
- Teste de tela e E2E provam o que a tela mostra e o que sai do navegador. **Não** provam a regra: quem a garante é o banco ou o serviço.
